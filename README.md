# CS 250 Module Four: Test Cases for SNHU Travel

Completed test case template for the Agile tester role.

## Contents
- Initial test cases (Test Case #1, #2, #3) based on original user stories.
- Revised test cases based on Product Owner clarifications and the Top Destinations Slide Show wireframe.

## User Stories Covered
1. **Top Destinations / Top 10 Trips** – View popular vacation packages.
2. **Trip Search and Filter** – Columns for name, location, price, description; sortable by user ratings; price range filter.
3. **Mobile App** – Core features (with limitations noted after clarification that it is more of an epic).

## Key Revisions
- Top destinations changed from a static ordered list page to an interactive slideshow (large image, description below, Next/Previous navigation).
- Search results clarified for column headers, one-line descriptions, and sorting.
- Mobile app limited to essential browse/view functions aligned with the slideshow format.

Test cases include detailed steps, inputs, and clear pass/fail expected results.
